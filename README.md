# 📋 TaskFlow

## 📖 Overview

TaskFlow is a web-based To-Do List application designed to help users organize and manage daily tasks efficiently.  
It allows users to create an account, manage tasks, track completion status, and filter tasks through a clean and responsive interface.

This project is built using PHP, MySQL, HTML, CSS, and JavaScript.

---

# 🚀 Features

## 👤 User Authentication
- User Registration and Login
- Secure Password Hashing
- Session-Based Authentication
- Logout Functionality

## ✅ Task Management
- Add, Edit, and Delete Tasks
- Mark Tasks as Completed
- Task Status Filtering
- Search Tasks

## 🎨 User Interface
- Responsive Dashboard Design
- Interactive UI using JavaScript
- Clean and Modern Layout

# ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/taskflow.git
```

2. Move the project folder into:

```plaintext
C:/xampp/htdocs/taskflow
```

3. Start Apache and MySQL in XAMPP

4. Create a database named:

```plaintext
taskflow_db
```

5. Import the SQL tables

6. Open in browser:

```plaintext
http://localhost/taskflow
```
